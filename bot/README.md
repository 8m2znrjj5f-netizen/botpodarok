# Бот-подарок ❤️

Telegram-бот на **aiogram 3.x**: присылает фото пары и открывает мини-приложение
(`index.html` из корня проекта) прямо внутри Telegram.

```
подарок/
├── index.html          ← мини-приложение (фронтенд)
├── css/ js/ assets/    ← статика мини-приложения, photo.jpg
└── bot/
    ├── bot.py          ← этот бот
    ├── requirements.txt
    ├── .env.example    ← шаблон настроек
    └── .env            ← твои секреты (создаётся вручную, в git не попадает)
```

## 1. Создать бота в BotFather

1. Открой [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Придумай имя и юзернейм (должен заканчиваться на `bot`).
3. Скопируй токен вида `123456789:AA...` — он понадобится в `bot/.env`.

## 2. Создать Web App в BotFather

1. В BotFather: `/newapp` → выбери своего бота.
2. Заполни: название, описание, иконку (640×360), при желании GIF.
3. На шаге **Web App URL** укажи публичный **HTTPS**-адрес мини-приложения
   (например, `https://username.github.io/gift/`).
   HTTP и `localhost` Telegram не примет — это требование платформы.
4. После создания приложение будет доступно по ссылке `t.me/<бот>/<короткое_имя>`.

## 3. Настроить кнопку меню

Бот сам ставит постоянную кнопку меню при запуске
(`set_chat_menu_button` с `MenuButtonWebApp`) — мини-приложение открывается
из поля ввода. Вручную это можно сделать так:

1. BotFather → `/mybots` → твой бот → **Bot Settings** → **Menu Button**.
2. **Configure menu button** → пришли HTTPS-адрес мини-приложения.
3. Отредактируй текст кнопки (например, «Открыть подарок ❤️»).

> Если позже поменяешь `WEBAPP_URL` в `bot/.env`, просто перезапусти бота —
> кнопка меню обновится сама.

## 4. Захостить статику по HTTPS

Mini App — это обычный статичный сайт. Нужен только HTTPS-адрес.

**GitHub Pages (бесплатно, навсегда)**

1. Залей `index.html`, `css/`, `js/`, `assets/` в репозиторий на GitHub.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет на `https://<логин>.github.io/<репозиторий>/`.

**Vercel (бесплатно)**

1. [vercel.com](https://vercel.com) → **Add New… → Project** → импортируй репозиторий
   (или просто перетащи папку в окно дашборда).
2. Framework Preset: **Other**, Build Command и Output Directory оставь пустыми.
3. Получишь адрес вида `https://<проект>.vercel.app`.

**Netlify (бесплатно)**

1. [app.netlify.com/drop](https://app.netlify.com/drop) → перетащи папку с проектом.
2. Адрес вида `https://<случайное-имя>.netlify.app` (можно переименовать в настройках).

**Быстрая локальная проверка через ngrok**

```powershell
# в папке с index.html (корень проекта)
python -m http.server 8000
# во втором окне
ngrok http 8000
```

ngrok выдаст `https://<случайные-символы>.ngrok-free.app` — этот адрес временно
пропиши в `WEBAPP_URL`. Ссылка живёт, пока запущен ngrok, и меняется после
перезапуска (перезапусти бота, чтобы обновить кнопку).

## 5. Запустить бота

```powershell
cd bot
Copy-Item .env.example .env      # затем открой bot/.env и вставь BOT_TOKEN и WEBAPP_URL
pip install -r requirements.txt
python bot.py
```

`bot/.env` подхватывается автоматически (через `python-dotenv`); переменные
окружения `BOT_TOKEN` и `WEBAPP_URL` тоже работают и имеют приоритет над `.env`:

```powershell
$env:BOT_TOKEN = "123456789:AA..."
$env:WEBAPP_URL = "https://example.com/"
python bot.py
```

В консоли появится примерно это:

```
12:00:00 | INFO     | gift-bot | Бот @my_gift_bot (id=123456789) на связи.
12:00:00 | INFO     | gift-bot | Мини-приложение: https://example.com/
12:00:00 | INFO     | gift-bot | Кнопка меню «Открыть подарок ❤️» установлена для всех чатов.
12:00:00 | INFO     | gift-bot | Слушаю сообщения… (Ctrl+C — остановить)
```

Если `WEBAPP_URL` не начинается с `https://` или не задан токен, бот не стартует
и пишет в лог, что именно поправить (без трейсбека). Остановка — `Ctrl+C`.

## Частые вопросы

- **«Кнопка не открывает мини-приложение»** — проверь, что `WEBAPP_URL`
  начинается с `https://`, отдаёт тот самый `index.html` и открывается
  в браузере без авторизации.
- **«Фото не пришло»** — `bot.py` ищет `assets/photo.jpg` рядом с папкой `bot/`.
  Проверь, что файл на месте; бот всё равно отправит кнопку, но без фото.
- **«Нужен ли веб-сервер для бота?»** — нет, используется long polling,
  входящие порты и домен для бота не нужны.
- **Токен утёк?** — BotFather → `/revoke`, выпусти новый и обнови `bot/.env`.

## Проверка синтаксиса без запуска

```powershell
python -m py_compile bot.py
```
