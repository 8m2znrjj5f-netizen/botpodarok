# Подарок ❤️ — мини‑приложение для Telegram

Маленький сайт‑открытка: **сердце, которое собирается из формулы**, живой счётчик
«время вместе» с 26.10.2025, теорема о любви, формула Эйлера, письмо и фото.
Открывается как **Telegram Mini App** — по кнопке в боте или из меню чата.

```
подарок/
├── index.html          ← страница мини-приложения
├── css/style.css       ← палитра и вся вёрстка
├── js/app.js           ← сердце, счётчик, лайтбокс, Telegram SDK
├── assets/photo.jpg    ← фото пары (720×1280)
├── bot/
│   ├── bot.py          ← Telegram-бот на aiogram 3 (отправляет фото + кнопку)
│   ├── requirements.txt
│   ├── .env.example    ← шаблон BOT_TOKEN / WEBAPP_URL
│   └── README.md       ← BotFather + хостинг + запуск бота
└── README.md           ← этот файл
```

## Что есть на странице

| Блок | Что делает |
|---|---|
| **Сердце** | Неявная кривая `(x² + y² − 1)³ − x²y³ = 0`: частицы собираются в сердце, бьются в такт, разлетаются от нажатия |
| **Время вместе** | Счётчик дней/часов/минут/секунд в реальном времени с `26.10.2025 00:00` (МСК), тик выровнен по секунде |
| **Теорема** | Текст теоремы и доказательства: от противного, индукция, предельный переход, следствия |
| **Формула Эйлера** | `e^(iπ) + 1 = 0` с золотым свечением |
| **Письмо** | Поздравление с годовщиной |
| **Фото** | Карточка с подписью; по нажатию открывается на весь экран |

Палитра: `#1B1030` фон · `#3B2566` фиолетовый · `#F472B6` розовое свечение ·
`#FDE68A` золото для формул · `#F5E9FF` текст.

## Посмотреть локально (без Telegram)

Из корня проекта:

```powershell
python -m http.server 8000
```

И открыть <http://localhost:8000>. Telegram-скрипт с `telegram.org` в обычном
браузере просто не активируется — страница работает и без него.

> Открывать `index.html` двойным щелчком тоже можно (`file://`), но тогда
> браузер может ругаться на загрузку `assets/photo.jpg` — локальный сервер надёжнее.

## Открыть в Telegram

1. Захостить папку `index.html` + `css/` + `js/` + `assets/` по **HTTPS**
   (GitHub Pages / Vercel / Netlify — бесплатно).
2. В [@BotFather](https://t.me/BotFather): `/newbot` → токен, `/newapp` → URL мини‑приложения.
3. В папке `bot/`: `Copy-Item .env.example .env`, вписать `BOT_TOKEN` и `WEBAPP_URL`,
   затем `pip install -r requirements.txt` и `python bot.py`.

Подробная пошаговая инструкция — в [bot/README.md](bot/README.md).

## Что легко поменять

- **Дату отсчёта** — `const START = new Date("2025-10-26T00:00:00+03:00")` в `js/app.js`.
- **Тексты** теоремы, письма, заголовки — в `index.html`.
- **Фото** — заменить `assets/photo.jpg` (лучше вертикальное, 9:16).
- **Цвета** — переменные `--bg`, `--violet`, `--pink`, `--gold`, `--text` в начале `css/style.css`.

## Технические детали

- Чистая статика без сборки и без зависимостей: HTML + CSS + JS.
- Telegram WebApp SDK: `ready()`, `expand()`, цвет шапки и фона, отключение
  свайпа-закрытия, haptic-отклик, учёт `safe-area` и высоты viewport.
- Анимации останавливаются, когда сердце вне экрана или вкладка скрыта
  (экономия батареи), и уважают `prefers-reduced-motion`.
- Все пути относительные — сайт работает и в подпапке GitHub Pages.
- Никаких внешних шрифтов и картинок, кроме фото и SDK Telegram: страница
  не «поедет», если что-то из CDN недоступно.
